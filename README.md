# ระบบสมุดโทรศัพท์บุคลากร (GitHub Pages + Google Sheets)

ระบบตัวอย่างพร้อมใช้งาน ประกอบด้วยหน้าเว็บสาธารณะเพื่อค้นหารายชื่อ และ Google Sheets สำหรับเจ้าหน้าที่ผู้ดูแลข้อมูล

## ฟังก์ชัน

- แสดงข้อมูลหลักตามตัวอย่าง: **ชื่อ - นามสกุล** และ **เบอร์โทรศัพท์**
- ช่องค้นหาชื่อ นามสกุล หมายเลขโทรศัพท์ ฝ่าย/แผนก และตำแหน่ง
- เลือกฝ่ายหรือแผนก, เรียงชื่อภาษาไทย, แบ่งหน้า
- รองรับคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ
- กดคัดลอกเบอร์ หรือแตะปุ่มโทรออกบนมือถือ
- ส่งออก CSV (เฉพาะข้อมูลที่ปรากฏตามตัวกรอง) และพิมพ์หรือบันทึก PDF ผ่าน Print ของเบราว์เซอร์
- แยกชื่อกับนามสกุลเป็นคนละคอลัมน์ใน Google Sheets
- หน้าเว็บอ่านอย่างเดียว; แก้ไขรายชื่อได้จาก Google Sheets เฉพาะผู้ได้รับสิทธิ์แก้ไข
- **ไม่มีฟังก์ชันรับข้อมูลแก้ไขจากเว็บหรือ API เขียนข้อมูลสาธารณะ**
- แสดงบนหน้าเว็บ **เฉพาะแถวที่ติ๊กช่อง “เผยแพร่”** เท่านั้น

## ขั้นที่ 1: สร้าง Google Sheets

1. เข้า https://sheets.google.com แล้วสร้างไฟล์ใหม่ เช่น `ฐานข้อมูลสมุดโทรศัพท์บุคลากร`
2. ไปที่ **ส่วนขยาย (Extensions) > Apps Script**
3. ลบโค้ดตัวอย่างเดิม แล้วนำไฟล์ `Code.gs` ในชุดนี้ไปวางทั้งหมด
4. กด Save
5. เลือกฟังก์ชัน `setupPhonebook` จากรายการฟังก์ชัน กด Run และอนุญาตสิทธิ์ในบัญชีเจ้าของ
6. กลับมาที่ Google Sheets แล้วรีเฟรช จะพบแท็บชื่อ **รายชื่อ** พร้อมหัวตาราง:

   | รหัส | ชื่อ | นามสกุล | เบอร์โทรศัพท์ | ฝ่าย/แผนก | ตำแหน่ง | เผยแพร่ |
   |---|---|---|---|---|---|---|
   | (เว้นว่างได้) | ใส่ชื่อ | ใส่นามสกุล | ใส่เบอร์ | ใส่ฝ่าย | ใส่ตำแหน่ง | ติ๊กช่อง |

7. ใส่ข้อมูลบุคลากรจริงในแถวที่ 2 เป็นต้นไป โดยคอลัมน์เบอร์โทรศัพท์กำหนดเป็นข้อความ เพื่อรักษาเลข `0` ข้างหน้า
8. เลือกติ๊กช่อง **เผยแพร่** (TRUE) เฉพาะข้อมูลที่ได้รับอนุญาตให้เปิดเผย
9. แชร์สิทธิ์ **Editor** ของ Google Sheets ให้เฉพาะผู้ดูแลที่ได้รับมอบหมาย

> **ห้ามแชร์ Google Sheets เป็น “Anyone with the link can edit”** และห้ามใส่ข้อมูลส่วนบุคคลที่ไม่ได้รับอนุญาตให้เผยแพร่

## ขั้นที่ 2: เผยแพร่ Google Apps Script เป็น API

1. ในหน้า Apps Script ให้คลิก **Deploy > New deployment**
2. เลือก Type: **Web app**
3. ตั้งค่าดังนี้
   - **Execute as:** Me (บัญชีเจ้าของ)
   - **Who has access:** Anyone
4. กด Deploy และอนุญาตสิทธิ์ตามที่ระบบถาม
5. คัดลอก **Web app URL** ซึ่งจะมีรูปแบบ `https://script.google.com/macros/s/.../exec`
6. ทดลองเปิด URL ในเบราว์เซอร์ ต้องเห็นข้อมูล JSON ลักษณะ `{"ok":true,"contacts":[],"count":0,...}` (เมื่อยังไม่มีรายชื่อที่เผยแพร่)

**ข้อควรระวัง:** เว็บแอปนี้อ่านข้อมูลที่ถูกทำเครื่องหมายให้เผยแพร่แบบสาธารณะได้ หากรายชื่อเป็นข้อมูลภายในที่ห้ามเปิดเผยสู่สาธารณะ อย่าเผยแพร่ในรูปแบบนี้ ควรใช้ระบบที่บังคับล็อกอินก่อนอ่านข้อมูลแทน

> อย่าใช้ URL จาก Apps Script ของระบบอื่น ต้อง Deploy จาก `Code.gs` ชุดนี้

## ขั้นที่ 3: เชื่อมต่อหน้าเว็บกับ API

1. เปิดไฟล์ `index.html` ด้วย Notepad หรือ VS Code
2. ค้นหาบรรทัด:

```js
const CONFIG = {
  apiUrl: '',
  organizationName: 'วิทยาลัยการอาชีพนครยะลา',
  pageSize: 12,
  timeoutMs: 20000
};
```

3. นำ URL Web App จากขั้นที่ 2 ใส่ใน `apiUrl` ภายในเครื่องหมาย `'...'`
4. ปรับชื่อหน่วยงานได้ที่ `organizationName`
5. บันทึกไฟล์

หากยังไม่ระบุ URL หน้าเว็บจะแสดงรายชื่อจำลองที่มีเบอร์ `X` เพื่อทดลองหน้าตาเว็บเท่านั้น **ไม่ใช่ข้อมูลจริง**

## ขั้นที่ 4: ฝากเว็บบน GitHub Pages

1. เปิด https://github.com/new และสร้าง Repository ใหม่ เช่น `staff-phonebook`
2. เลือก **Public** แล้วกด Create repository
3. อัปโหลดไฟล์ `index.html` ไปยังโฟลเดอร์หลัก (root) ของ Repository
4. ไปที่ **Settings > Pages**
5. เลือก **Deploy from a branch** และ Branch เป็น `main` / `/(root)` แล้ว Save
6. รอการเผยแพร่ GitHub Pages แล้วเปิด URL ตัวอย่าง `https://USERNAME.github.io/staff-phonebook/`

> ไม่ต้องอัปโหลดไฟล์ `Code.gs` เข้า GitHub Pages เพราะสคริปต์ทำงานฝั่ง Google Apps Script

## การเพิ่ม / แก้ไข / ลบข้อมูล

- **เพิ่ม:** เพิ่มแถวใหม่ในแท็บ `รายชื่อ` ใส่ชื่อ นามสกุล เบอร์ และติ๊ก “เผยแพร่”
- **แก้ไข:** เปลี่ยนค่าใน Google Sheets แล้วรีเฟรชเว็บ
- **ซ่อน:** ยกเลิกเครื่องหมายถูก “เผยแพร่”
- **ลบ:** ผู้ดูแลลบแถวใน Google Sheets

> หากแก้ไขโค้ด `Code.gs` หลัง Deploy แล้ว ให้ไปที่ **Deploy > Manage deployments > Edit > New version > Deploy** เพื่อให้ลิงก์ `/exec` ทำงานด้วยโค้ดใหม่

## การรักษาความปลอดภัย

- API รองรับ **GET แบบอ่านอย่างเดียว** ไม่มี `doPost` และไม่มี endpoint สำหรับเพิ่ม แก้ไข หรือลบ
- ไม่มีการเก็บรหัสผ่าน หรือ Secret ใด ๆ ไว้ในหน้า GitHub Pages
- ฝั่ง Apps Script กรองข้อมูลก่อนส่งออก โดยเลือกเฉพาะแถว `เผยแพร่=TRUE`
- ผู้ดูแลข้อมูลต้องได้รับสิทธิ์แก้ไข Google Sheets
- **เว็บไซต์ GitHub Pages เป็น Public** และผู้ใดก็ตามที่ทราบ URL API สามารถอ่านรายชื่อที่เผยแพร่ได้ ไม่เหมาะกับเบอร์ส่วนตัวที่ไม่ได้รับความยินยอม
- หากต้องการจำกัดให้ใช้เฉพาะบุคลากรภายในสถานศึกษา ต้องปรับสถาปัตยกรรมเป็นแบบล็อกอินก่อนอ่าน ไม่ใช่ใช้ Public JSONP API นี้
